Flexbox and Grid Layout Guide

This page uses both layout systems, and explains each one next to a live example. Resize the browser window to see the layout change.

Flexbox: a row of items that share space

Flexbox lays items out in one direction at a time, in a row or in a column. It suits menus, toolbars and card rows. The menu at the top of this page and the three cards below are both flexbox layouts.

The cards sit in a container with display: flex. Each card has flex: 1 1 220px, so it can grow, can shrink, and starts at 220px wide. When the row is too narrow, flex-wrap: wrap moves a card down to the next line.

Container CSS

display: flex;
flex-wrap: wrap;
gap: 16px;
justify-content: space-between;

Flexbox settings and their effect

PropertyWhat it does
display: flexTurns the container into a flex container. Its children become flex items.
flex-directionrow (default) lays items side by side. column stacks them.
justify-contentSpaces items along the main axis: center, space-between, space-around.
align-itemsAligns items across the other axis: center, stretch, flex-start.
flex-wrapLets items move to a new line when they do not fit.
flex: grow shrink basisSets how an item grows, shrinks and what size it starts at.
gapAdds space between items without using margins.

Grid: rows and columns together

Grid controls rows and columns at the same time. It suits whole page layouts and galleries. The demo below has three equal columns made with grid-template-columns: repeat(3, 1fr). The 1fr unit means one share of the free space. The wide box uses grid-column: span 2 to cover two columns.

Grid settings and their effect

PropertyWhat it does
display: gridTurns the container into a grid container.
grid-template-columnsDefines the number and width of columns, for example 1fr 2fr or repeat(3, 1fr).
grid-template-rowsDefines the height of rows.
gapSets the space between rows and columns.
grid-column / grid-rowPlaces an item or makes it span several cells.
align-items / justify-itemsAligns items inside their cells.

How the layout responds to screen size

Flexbox cards: three cards fit on one row on a wide screen. On a tablet two cards fit, and on a phone each card has its own row. This happens automatically because of flex-wrap and the 220px basis.

Grid boxes: a media query changes the column count. Above 700px there are 3 columns. Between 480px and 700px there are 2 columns. Below 480px there is 1 column, and the wide box stops spanning.

Explanation sections: the text and the CSS box sit in a two-column grid (2fr 1fr). Below 700px it becomes one column.

Menu: the icon bar uses flexbox, so every link shares the width equally. On small phones the text size shrinks.

Media query

@media (max-width: 700px) {
  .grid-demo {
    grid-template-columns: 1fr 1fr;
  }
}

Features and when to use them

FeatureHow to use it
Icon bar menuPut links in a nav with display: flex and flex: 1 on each link. Use position: sticky to keep it at the top.
Flexbox or Grid?Use flexbox for a single row or column. Use grid when you need rows and columns together.
repeat(auto-fit, minmax(200px, 1fr))Makes a grid that picks its own column count without media queries.
ImagesUse width: 100% and object-fit: cover so images fill their card at any size.
Viewport meta tagNeeded in the head so phones use the real screen width.
